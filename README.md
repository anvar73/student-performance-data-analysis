# Student Performance Data Analysis

## Project Overview

This beginner-level data analysis project explores student attendance and academic scores using Python. It uses a fictional sample dataset to practice data analysis and visualization.

## Objectives

- Load and inspect student data from a CSV file.
- Calculate average attendance and subject scores.
- Compare Mathematics and Science performance.
- Identify the student with the highest average score.
- Visualize subject scores using a bar chart.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- CSV
- Visual Studio Code

## Dataset

The file `student.csv` contains 8 fictional student records with the following columns:

- Student
- Attendance
- Math_Score
- Science_Score

## Key Findings

Based on the sample dataset:

- Average Mathematics score: 77.25
- Average Science score: 79.625
- Average attendance: 83.25
- Highest average score: Student D, with 95.0

These findings describe only the fictional sample data and should not be generalized to real students.

## Visualization

The file `student_performance.png` contains a bar chart comparing Mathematics and Science scores for each student.

## How to Run

1. Install Python.
2. Install the required libraries:
   `python -m pip install pandas matplotlib`
3. Keep `main.py` and `student.csv` in the same project folder.
4. Run:
   `python main.py`
